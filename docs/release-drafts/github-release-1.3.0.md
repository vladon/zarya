# Zarya 1.3.0

Stable release with bundled runetfreedom geo data and additional geo sources.

## Highlights

- Bundled pinned runetfreedom `geoip.dat` / `geosite.dat` next to Xray for offline bypass routing; Geo Data Manager still updates/switches sources
- Built-in geo sources: runetfreedom (default), Loyalsoldier, Chocolate4U
- Continues shipping the pinned Xray seed

## Recommended mode

Use Xray system-proxy mode.

## Downloads

- Windows x64 portable ZIP
- macOS arm64 ZIP
- Linux x64 tar.gz

## Verify downloads

Use `SHA256SUMS.txt`.

## Experimental features

TUN/helper/kill switch remain experimental and are disabled by default.

## Known limitations

System proxy mode is not VPN mode. Some applications may ignore OS proxy settings.

## Issue reports

Use **Help → Create Diagnostics Bundle**.
Do not post raw proxy links or subscription URLs.
