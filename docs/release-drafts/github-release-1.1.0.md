# Zarya 1.1.0

Stable maintenance release with Hysteria2 support and Core Manager / UX fixes.

## Highlights

- Hysteria2 subscription import and Xray / sing-box runtime support
- Core Manager checksum and Update All improvements
- Share-link fixes (Shadowsocks SIP002, Trojan Reality)
- Geo Data Check Status feedback; fewer noisy start/update dialogs
- macOS Esc handling for Ok-only message boxes

## Recommended mode

Use Xray system-proxy mode.

## Downloads

- Windows x64 portable ZIP
- macOS arm64 ZIP
- Linux x64 tar.gz

## Verify downloads

Use `SHA256SUMS.txt`.

## Experimental features

TUN/helper/kill switch remain experimental and are disabled by default.

## Known limitations

System proxy mode is not VPN mode. Some applications may ignore OS proxy settings.

## Issue reports

Use **Help → Create Diagnostics Bundle**.
Do not post raw proxy links or subscription URLs.
