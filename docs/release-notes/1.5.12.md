# Zarya 1.5.12

## LCL release engineering

- Pinned Lazarus 4.8, FPC 3.2.2, Go 1.26.5, and MinGW-w64 GCC 16.1.0 with
  checksum-verified CI bootstrap.
- Added a version contract across CMake, Pascal, `Zarya.exe --version`, and PE
  file metadata.
- Added pinned SHA-256/PE/version/integration checks for external Xray,
  sing-box, V2Ray, Hysteria2, Mihomo, and `nekobox_core.exe` fixtures.
- Added hosted Windows LCL CI and opt-in self-hosted Windows 10/11 release
  gates.
- Restricted the portable archive to exactly `Zarya.exe` and
  `Zarya.exe.sha256`.
