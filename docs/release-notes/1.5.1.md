# Zarya 1.5.1

## Embedded cores

- Xray remains built into Zarya and starts in-process through the app-owned ABI bridge.
- sing-box `v1.13.12` is now built into `zarya-helper`; experimental TUN no longer starts or stores an external sing-box executable.
- TUN configuration is delivered to the authenticated helper IPC in memory. Release artifacts include the required bridge sidecar on Windows and Linux, and use the static helper bridge on macOS.

## Packaging and recovery

- Core Manager reports Xray and sing-box as built into Zarya; core updates are delivered by the application update.
- Missing or incompatible bridges use the repair/reinstall recovery path.
- Legacy `cores/singBoxPath` stays inert for one stable release and is excluded from backup export.
