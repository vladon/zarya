# Zarya 1.5.6

## LCL runtime workers

- Added Xray bridge ABI v2 with typed validation, runtime, and URL-probe
  requests.
- Added the JSON-only `--core-test-worker` protocol with diagnostics kept on
  stderr.
- Added dynamic TCP/UDP port allocation, bounded Real delay batches, and
  process-isolated embedded runtime tests.
- Kept system proxy activation outside worker tests and unchanged for the
  stable Qt client.
