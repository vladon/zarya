# Zarya 1.3.0

Stable release with bundled runetfreedom geo data and additional geo sources.

## Highlights

- **Bundled geo data** — release artifacts include pinned runetfreedom `geoip.dat` / `geosite.dat` under `cores/xray/` (next to the Xray seed) so bypass routing works offline. Refresh or switch sources via **Tools → Geo Data Manager**.
- **More geo sources** — built-ins: runetfreedom (default), Loyalsoldier, and Chocolate4U.
- **Bundled Xray** — continues to ship the pinned Xray seed from 1.2.0 for offline first start.

## Recommended mode

Use **Xray system-proxy** (Routing: Bypass LAN, DNS: Secure Remote DNS or System DNS).

## Downloads

- Windows x64 portable ZIP
- macOS arm64 ZIP
- Linux x64 tar.gz

## Verify downloads

Use `SHA256SUMS.txt`.

## Experimental features

TUN / helper / kill switch remain experimental and are disabled by default on stable.
