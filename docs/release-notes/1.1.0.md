# Zarya 1.1.0

Stable maintenance release with Hysteria2 support and Core Manager / UX fixes.

## Highlights

- **Hysteria2** share-link import and Xray / sing-box outbound support (`hysteria2://`, `hy2://`)
- Core Manager: Xray `.dgst` and GitHub asset digest checksums; skip up-to-date cores on Update All
- Shadowsocks SIP002 port parsing when a query string is present
- Trojan Reality share links keep `pbk` / `sid` / `spx`
- Status dashboard shows remaining setup steps when Xray is already installed
- Geo Data Manager Check Status logs progress (no longer a silent no-op)
- No modal popup after successful core updates
- No false start warning for default Bypass LAN (`AsIs`) + Secure Remote DNS
- macOS: Esc closes Ok-only message boxes; `scripts/build-macos.sh` helper

## Recommended mode

Use **Xray system-proxy** (Routing: Bypass LAN, DNS: Secure Remote DNS or System DNS).

## Downloads

- Windows x64 portable ZIP
- macOS arm64 ZIP
- Linux x64 tar.gz

## Verify downloads

Use `SHA256SUMS.txt`.

## Experimental features

TUN / helper / kill switch remain experimental and are disabled by default on stable.

Use **Help → Create Diagnostics Bundle**.
