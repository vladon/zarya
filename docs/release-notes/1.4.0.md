# Zarya 1.4.0

Stable release with WireGuard profiles through Xray, silent startup recovery, and the Desktop App Toolkit UI foundation.

## Highlights

- **WireGuard through Xray** — import `wireguard://` and `wg://` links, edit WireGuard profiles, and generate Xray userspace (`noKernelTun`) outbounds. Private keys and peer credentials follow the existing persistence and redaction rules.
- **Silent startup recovery** — after an unclean shutdown, Zarya restores stale system-proxy state, cleans temporary runtime configuration, and recovers managed-core state without blocking startup on a modal dialog.
- **Updated desktop UI foundation** — system, light, and dark themes plus a configured status strip built with Desktop App Toolkit (`lib_ui`).
- **Reproducible Windows releases** — Windows builds use static Qt 6.8.3 with the static MSVC runtime. Desktop App Toolkit is mandatory on every platform.
- **Offline first start retained** — release artifacts continue to include pinned Xray and runetfreedom `geoip.dat` / `geosite.dat`.

## Recommended mode

Use **Xray system-proxy** (Routing: Bypass LAN, DNS: Secure Remote DNS or System DNS).

## Downloads

- Windows x64 portable ZIP
- macOS arm64 ZIP
- Linux x64 tar.gz

Use `SHA256SUMS.txt` to verify downloads.

## Licensing

Zarya-authored source remains dual-licensed under MIT or GPLv3+. Official binaries link Desktop App Toolkit and are distributed under GPLv3+.

## Experimental features

sing-box TUN, helper service controls, kill switch, MSI installation, and app-update installation remain experimental and are disabled or hidden by default on the stable channel.

## Known limitations

System-proxy mode is not VPN mode. Some applications may ignore operating-system proxy settings.

## Issue reports

Use **Help → Create Diagnostics Bundle**. Do not post raw proxy links, private keys, or subscription URLs.
