# Zarya 1.5.0

Stable release focused on desktop system-proxy parity and failure-safe
operation.

## Highlights

- **KDE Plasma system proxy** — Plasma 5 and 6 use native KConfig tools to
  snapshot, apply, reload, and exactly restore `kioslaverc` proxy settings.
  Partial writes and KIO reload failures trigger rollback.
- **Consistent desktop behavior** — Windows, macOS, GNOME, KDE, and unsupported
  Linux desktops now share the same user-facing status and recovery semantics.
- **Safer imports and subscriptions** — VLESS, VMess, Trojan, Shadowsocks,
  Hysteria2, and WireGuard have consolidated valid/invalid coverage, including
  malformed encoding, IPv6, duplicate query keys, unsupported options, and
  mixed-validity subscriptions.
- **Non-destructive refresh failure** — a failed subscription refresh keeps
  the previously imported profiles unchanged.
- **Stronger privacy checks** — subscription warnings and logs no longer expose
  raw lines or source URLs, and every release archive is audited for user data,
  credentials, private keys, and raw credential-bearing share links.
- **Release gates on every platform** — full CTest, translation checks,
  packaging verification, checksums, and secret audits run for Windows, Linux,
  and macOS artifacts.

## Recommended mode

Use **Xray system-proxy** with Routing set to Bypass LAN and DNS set to Secure
Remote DNS or System DNS.

## Downloads

- Windows x64 portable ZIP
- macOS arm64 ZIP
- Linux x64 tar.gz

Verify downloads with the matching `.sha256` file or `SHA256SUMS.txt`.

## Licensing

Zarya-authored source remains dual-licensed under MIT or GPLv3+. Official
binaries link Desktop App Toolkit and are distributed under GPLv3+.

## Experimental features

sing-box TUN, helper service controls, kill switch, MSI installation, and app
update installation remain experimental and are disabled or hidden by default
on the stable channel.

## Known limitations

System-proxy mode is not VPN mode, and applications may ignore operating-system
proxy settings. KDE integration requires KConfig 5 or 6 tools and a usable
session D-Bus; Zarya reports the integration unavailable when they are absent.

## Issue reports

Use **Help → Create Diagnostics Bundle**. Do not post raw proxy links, private
keys, credentials, or subscription URLs.
