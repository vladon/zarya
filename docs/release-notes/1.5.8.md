# Zarya 1.5.8

## Migration and privacy

- Added staged migration validation for profiles, routing, DNS, and selected
  Qt settings before any LCL data is installed.
- Added reasoned fallback for invalid routing/DNS references and migration v2
  reporting.
- Preserved legacy data and added atomic rollback when validation or install
  fails.
- Hardened backups and diagnostics to exclude raw configs, credentials,
  external executables, and machine-specific absolute core paths.
