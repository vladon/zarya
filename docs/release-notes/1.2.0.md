# Zarya 1.2.0

Stable release with a bundled Xray seed, a single mixed local proxy port, and Test URL presets.

## Highlights

- **Bundled Xray** — release artifacts include a pinned Xray core (`v26.3.27`) under `cores/xray/` so first launch works offline. Replace or update via **Tools → Core Manager**, or point Settings at an external binary.
- **Mixed inbound** — one local proxy port (default `10808`) for SOCKS5 + HTTP instead of separate SOCKS/HTTP ports. Existing `socksPort` settings migrate automatically.
- **Test URL presets** — choose common latency-test endpoints; Cloudflare is the default.

## Recommended mode

Use **Xray system-proxy** (Routing: Bypass LAN, DNS: Secure Remote DNS or System DNS).

## Downloads

- Windows x64 portable ZIP
- macOS arm64 ZIP
- Linux x64 tar.gz

## Verify downloads

Use `SHA256SUMS.txt`.

## Experimental features

TUN / helper / kill switch remain experimental and are disabled by default on stable.

## Issue reports

Use **Help → Create Diagnostics Bundle**.
Do not post raw proxy links or subscription URLs.
