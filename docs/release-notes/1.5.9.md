# Zarya 1.5.9

## Windows lifecycle

- Added typed application settings and the native LCL settings form.
- Added HKCU Run autostart with Windows command-line quoting and a focused
  regression test.
- Added `--minimized` startup and automatic connection only when the saved
  profile still exists and has a compatible available provider.
- Kept system proxy activation behind the existing readiness gate and retained
  exact WinINet state restoration during stop and shutdown.
