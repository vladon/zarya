# Zarya 1.5.7

## Routing, DNS, and geodata

- Added versioned routing and DNS stores with built-in and custom profiles.
- Added native LCL editors for rules, DNS servers, hosts, strategies, and
  fallbacks.
- Added adapter-specific capability validation so unsupported policy is
  blocked instead of silently discarded.
- Added checksum-verified, cancelable, atomic geodata installation in the
  user data directory.
