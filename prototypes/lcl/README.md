# Zarya LCL prototype

Небольшой Windows-прототип для проверки Lazarus/LCL как альтернативы Qt и
Delphi/VCL. Он специально использует стандартные LCL-контролы и создаёт формы
программно, без привязки к `.lfm`.

Что можно проверить:

- главное окно с operational status, таблицей профилей и журналом;
- Win32 tray: двойной клик, контекстное меню, скрытие окна при закрытии;
- светлую и тёмную палитру через `Инструменты → Настройки`;
- поведение стандартных контролов при Windows scaling 100%, 150% и 200%;
- клавиатурную навигацию и визуальную плотность LCL;
- mock-переход `остановлен → ожидание порта → подключён`.

Прототип не запускает Xray, не делает сетевых запросов, не читает рабочие
профили и не изменяет системный прокси.

## Сборка

Установить Lazarus с Free Pascal, затем выполнить:

```powershell
cd D:\projects\zarya\prototypes\lcl
.\build.ps1
.\bin\zarya-lcl-prototype.exe
```

Проект также можно открыть в Lazarus через `zarya_lcl.lpi` и запустить с F9.

## Чек-лист сравнения

1. Проверить размеры, шрифты и таблицу при 100%, 150% и 200% scaling.
2. Переключить светлую/тёмную тему и отметить нативные контролы, которые
   выбиваются из палитры.
3. Закрыть окно, вернуть его двойным кликом по tray icon, затем выйти через
   контекстное меню tray.
4. Выбрать профиль и нажать `Запустить`: системный прокси остаётся выключенным
   до окончания mock-проверки mixed-порта.
5. Пройти интерфейс только клавиатурой.

Это feasibility spike, а не начало миграции и не функциональная версия Zarya.
